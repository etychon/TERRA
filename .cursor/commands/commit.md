# /commit — public-ready git commit (TERRA)

Execute the **commit-public-repo** workflow:

1. Open and follow **`.cursor/skills/commit-public-repo/SKILL.md`** step by step (verify → summarize since `HEAD` → commit).
2. Run **`bash .cursor/skills/commit-public-repo/scripts/verify-public-ready.sh`** from the repo root before staging anything.
3. After committing, report the **commit hash** and the **title line** you used.

If verification fails or there is nothing to commit, say so clearly and stop without committing.
